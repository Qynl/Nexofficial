Models & providers

Nex separates the planner (reasoning, architecture) from the builder (the hands that execute the plan through MCP tools). The builder is the only role that runs often, so a rate-limited builder fails over automatically — same plan, different model. Nothing but MCP tools can change the game, whichever provider is active.

Roles

Only the providers named here are ever tried. A configured provider that is not named can still be chosen as the primary — it just never enters a chain by itself.

Rate budget: the NVIDIA NIM free tier allows roughly 40 requests per minute, with per-model limits NVIDIA does not publish and no usage API — so Nex counts the requests itself and routes around a rate-limited provider instead of burning 429s. Test fetches the live model list of a provider, which is always more accurate than any list shipped in the code.
